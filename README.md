# Анализ лояльности пользователей Яндекс Афиши

Приложение анализирует заказы сервиса Яндекс Афиша (июнь–октябрь 2024) из
базы данных `data-analyst-afisha`: приводит выручку к единой валюте,
строит профили пользователей и проверяет продуктовые гипотезы о том,
какие характеристики первого заказа связаны с возвратом пользователей.

Логика оформлена в виде класса `DataProcessor` (`src/processing.py`):
загрузка данных, предобработка, построение профилей, расчёт retention
по сегментам и корреляционный анализ (`phi_k`). Файл `main.py` —
точка входа, которая запускает пайплайн и печатает итоговый отчёт.

## Установка и запуск

1. Клонируйте репозиторий и создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите реальные доступы к БД:

   ```bash
   cp .env.example .env
   ```

3. Скачайте `final_tickets_tenge_df.csv` по [ссылке](https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv)
   и положите в папку `data/`.

4. Выгрузите сырые данные о заказах из БД в `data/orders_raw.csv`
   (выполняется один раз, доступы берутся из `.env`):

   ```bash
   python3 -c "from dotenv import load_dotenv; load_dotenv(); \
   from src.processing import DataProcessor; DataProcessor().extract_from_db()"
   ```

5. Запустите приложение:

   ```bash
   python3 main.py
   ```

## Итоги анализа

- В выборке 21 622 пользователя (после удаления неявных дубликатов
  заказов, аномальной выручки/числа заказов). Доля пользователей
  с 2+ заказами — 61.3%.
- Главные точки входа: мобильные устройства (83% пользователей) и
  концерты (44%); треть новых пользователей — из одного региона.
- Возврат выше среднего у пользователей, впервые пришедших на выставки
  и в театр, и у пользователей с десктопа; ниже среднего — у пришедших
  на спорт и на ёлки.
- Гипотеза «спорт возвращает лучше концертов» не подтвердилась — верно
  обратное (p ≈ 0.0009). Гипотеза «в крупных регионах выше возврат»
  подтвердилась лишь частично: связь умеренная (Спирмен ≈ 0.41), но не
  строгая — среди крупных регионов есть и лидеры, и аутсайдеры.
- День недели первой покупки статистически значимо, но очень слабо
  связан с возвратом (разброс ≈3.5 п.п.) — как рычаг сегментации
  практической ценности не имеет.
- Из признаков, известных на момент первого заказа, сильнее всего
  с числом заказов связан регион (`phi_k` ≈ 0.12), остальные — слабо.
  Средний чек и интервал между покупками коррелируют заметнее, но
  известны только постфактум, поэтому непригодны как предикторы
  возврата сразу после первого заказа (data leakage).

## Рекомендации для Яндекс Афиши

1. Развивать сегменты выставок и театра — они уже демонстрируют
   повышенную лояльность.
2. Уделить дополнительное маркетинговое внимание сегментам «спорт» и
   «ёлки» — ниже возврата при заметном объёме новых пользователей.
3. Не полагаться на размер региона как самостоятельный показатель
   потенциала — строить региональные кампании на данных конкретного
   региона.
4. В модели прогноза возврата сразу после первого заказа использовать
   только доступные на этот момент признаки (регион, тип мероприятия,
   устройство, день недели), не используя средний чек и интервал между
   покупками — они формируются только после того, как пользователь уже
   вернулся.
